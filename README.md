## Arcade Taiko Drum Controls

Taiko no Tatsujin System 246 arcade definitions can select the drum JVS input path with `jvsmode=drum`.
In drum mode, normal pad bindings are mirrored to eight JVS analog drum channels:

| Taiko input | PS2 controller button |
| --- | --- |
| Left Men (Don) | L1 |
| Left Fuchi (Ka) | L2 |
| Right Men (Don) | R1 |
| Right Fuchi (Ka) | R2 |

General arcade inputs still apply alongside the drum controls:

| Arcade input | PS2 controller button |
| --- | --- |
| Service/Coin | Select |
| Test | JVS Test Mode binding |
